# Decodex

Decodex is a 100% offline crossword puzzle game for Android.

## Features
- **Puzzle Selection**: Choose from multiple crossword puzzles.
- **Offline First**: Puzzles are loaded from a local SQLite database.
- **Real-time Timer**: Track your solve time for each puzzle.
- **Win Detection**: Automatic verification of answers with a victory celebration.

## Tech Stack
- **Kotlin** & **Jetpack Compose**
- **Room Database** for local storage.
- **Material 3** Design.
